# 横吹 SFX 响度曲线后处理器：原理

## 一句话原则

音频模型基座负责生成一份完整、自然的单次音色底稿；用户只用曲线安排声音何时出现、每一击多响、起落有多快。曲线由本地后处理器执行，不让音频模型基座理解或跟随曲线，也不通过曲线改变音高或频谱。

候选数为 4 时，模型生成 4 份不同种子的单次底稿；后处理器将同一条响度曲线分别应用到这 4 份底稿，得到 4 个候选结果。曲线上有 3 个清晰峰，就形成 3 个声音事件，不需要让模型分别生成 3 次攻击。

## 1. 各部分职责

| 部分 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| 用户描述及可选参考素材 | 指定声音是什么、材质和音色特征 | 指定曲线的频率轨迹 |
| 音频模型基座 | 生成真实的声音材质与单次底稿 | 识别曲线、决定曲线峰数或事件时间 |
| 响度曲线编辑器 | 决定声音事件的时间位置、相对音量和响度起落形状 | 改变音高、播放速度或材质频谱 |
| 本地后处理器 | 从底稿构建曲线事件、应用平滑增益、处理边界并输出音频 | 再次调用生成模型 |

曲线表达的是“声音在时间轴上有多响”，不是 Hz 曲线。音高和频谱应保留在 音频模型基座生成的底稿中；若希望木头更空、金属更亮、脚步更厚，应通过声音描述、标签或参考素材改变底稿，而不是拖动曲线模拟这些材质。

## 2. 信号处理原理

把模型生成的单声道或多声道底稿记作 `x[n]`，把编辑器绘制的响度包络记作 `A(t)`。后处理器将包络采样到音频采样点，得到增益 `g[n]`，再相乘：

```text
y[n] = g[n] · x[n]
```

`g[n]` 是对原始信号振幅的控制。它会让已有声音变响、变轻或接近静音，但不会把一个低音变成高音，也不会把原始波形快放或慢放。底稿的采样速度和音高保持不变。

曲线横轴映射到目标音频的时间；纵轴 `A(t) ∈ [0, 1]` 表示相对响度/增益。横轴决定事件何时发生、持续多久；纵轴决定它相对多响。若某段曲线不降到接近零，该处表示声音变轻但未完全中断；若要听见明显停顿，应把相邻事件之间的谷底拉低。

### 导数与“快慢”

响度变化速度由一阶导数表示：

```text
A'(t) = dA(t) / dt
```

- `A'(t) > 0`：响度正在上升；绝对值越大，起音越急。
- `A'(t) < 0`：响度正在下降；绝对值越大，收音越急。
- `|A'(t)|` 接近 0：响度变化平缓，声音更渐进地进入或退出。
- `A'(t) = 0`：可能是峰顶或谷底；还要看导数变号方向才能区分。

如果用归一化时间 `τ=t/T` 绘图，`T` 是目标时长，则：

```text
dA/dt = (1/T) · dA/dτ
```

因此，同样的归一化曲线放到更长的目标时长上，实际响度变化会更缓。但这只改变增益包络的起落速度，不是音频慢放，也不改变音高。

## 3. 怎样从曲线得到多次声音事件

一个完整的“响度凸起”对应一次声音事件。以一座峰为例：

```text
前一谷底  →  响度上升  →  峰顶  →  响度下降  →  后一谷底
              A'(t) > 0    +→−      A'(t) < 0
```

峰顶 `tₚ` 是导数由正变负的位置，理想光滑曲线处 `A'(tₚ)=0`。峰两侧的谷底用于分隔相邻事件；谷底通常是导数由负变正的位置。**不能把“导数等于 0”单独当作切点**：峰顶和谷底的导数都可能为零，必须结合变号方向、峰值显著度和相邻谷底判断。

曲线端点的响度即使为零，端点处的导数也不一定为零。因此，“从零上升再回到零”是响度形状的描述，不要求两端导数也为零。

三座明显的峰通常表示三次事件。后处理器按相邻峰之间的谷底确定边界；若谷底没有接近零，事件之间仍可能有连续的残留声。实际自动检测应先对控制曲线轻度平滑，并使用最小峰高差、最小事件间距和迟滞阈值，避免细小控制点抖动被当成额外攻击。用户明确放置的事件标记优先于自动猜测。

这里的“切分”是事件时间窗和音量包络的切分，不是把 WAV 在峰值处硬切成碎片。硬切可能产生咔哒声；事件边界需要连续包络、短淡入淡出或平滑交叉淡化。底稿的材质片段可供每个事件复用，但不得因重采样快放而偷偷改变音高。

## 4. 曲线该怎么画

1. **先确定声音本身。** 在用户描述中写清声源和材质，例如“厚雪上的脚步，松软、细碎的挤压声”。曲线不负责把普通底稿变成雪地材质。
2. **用横轴安排事件。** 横向位置决定每一击出现的时间；事件之间留多大间隔也由横轴决定。
3. **用峰高安排相对音量。** 峰越高，该事件相对越响。三座峰高度不同，可以表示轻—重—轻等力度关系。
4. **用上升斜率安排起音。** 曲线上升越陡，声音越快变响；上升越缓，声音越渐进。
5. **用下降斜率安排收音和尾部。** 下降越陡，声音越快收住；下降越缓，尾音越长、音量淡出越慢。
6. **用谷底安排停顿。** 谷底接近零会形成清楚的静音间隔；谷底较高则事件之间仍会听见底稿。
7. **试听并导出。** 先确认事件数量、间距和音量轮廓，再调整声音描述或参考素材来改善材质。不要试图通过曲线修复错误材质。

### 例：三次斩击

用户先让 音频模型基座   生成一个单次、干净的斩击音色底稿；曲线上画三座凸起。第一峰短而陡表示短促起音和快速收音，第二峰更宽、下降更缓表示较长的响度尾部，第三峰放在需要的时间点并设置相对高度。三峰之间的谷底决定停顿。处理器按这条曲线组织三次事件，保持底稿音色，不对每一峰单独请求模型生成。

## 5. 不应发生的行为

- 曲线纵轴被解释成频率、音高、谱心或 Hz。
- 斜率被解释成播放速度或时间伸缩。
- 音频模型基座   被要求按峰数重复生成事件，导致模型调用数随曲线峰数增加。
- 将多个事件按波形硬切，造成爆音、咔哒声或突然截断尾音。
- 对每个事件分别做响度归一化，把用户设置的峰高差抹平。
- 把材质不准确归咎于响度曲线；材质应由底稿生成条件解决。

最终音频可以做一次整体电平安全处理（例如统一峰值限制），但不能逐事件独立 RMS 拉齐，否则不同峰的相对音量会被削弱。任何淡入淡出也必须服从用户绘制的事件边界和响度轮廓。

## 6. 术语

- **音色底稿**：音频模型基座   生成的一份单次声音材质，供本地事件处理复用。
- **响度包络**：随时间变化的增益函数 `A(t)`。
- **峰（局部最大值）**：一次事件响度最高处；导数通常由正变负。
- **谷底（局部最小值）**：相邻事件之间的低点；导数通常由负变正。
- **斜率**：响度随时间变化的速度，不是音频播放速度。
- **事件窗**：由前后谷底或明确事件标记确定的一次声音时间范围。
